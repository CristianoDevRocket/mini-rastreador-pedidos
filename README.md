# Mini Rastreador de Pedidos

Sistema simplificado de rastreamento de pedidos de delivery.

## Stack

- **Backend:** Java 21, Spring Boot 3, Spring Security, Spring Data JPA, SQLite, JWT
- **Frontend:** React, Vite, React Router, Axios

## Estrutura

- `backend/` — API REST
- `frontend/` — aplicação React
